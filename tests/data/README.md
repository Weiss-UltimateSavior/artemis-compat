These are synthetic 50 ms mono sine tones (440 Hz and 880 Hz), not game assets.
They exercise Artemis Vorbis intro/loop boundaries and mono-to-stereo output.

Generated with Python, NumPy and soundfile (libsndfile Vorbis encoder):

```python
import numpy as np
import soundfile as sf
for name, frequency in [("a", 440), ("b", 880)]:
    pcm = (np.sin(np.arange(2205) * 2 * np.pi * frequency / 44100) * 0.125).astype("float32")
    sf.write(f"tone_{name}.ogg", pcm, 44100, format="OGG", subtype="VORBIS")
```

`rectangle.ttf` is an original synthetic rectangle-glyph font generated by `generate_font.py` using fontTools. It tests placement and outline coverage without bundling a third-party font.
